# Bzden4ik Player

Музыка с YouTube за баллы канала Twitch — прямо в OBS. Зритель вставляет ссылку в награду, трек встаёт в очередь и играет на стриме; заказы проверяются (запрещённые слова, AutoMod, лимиты), баллы за отклонённые и сорвавшиеся заказы возвращаются сами.

**Скачать:** [последняя версия](../../releases/latest/download/Bzden4ikPlayer.zip) · [все версии](../../releases)

Пошаговая установка с анимированной копией OBS — на сайте плеера. Кратко — в `README.txt`.

## Что внутри

| Файл | Зачем |
|---|---|
| `redeem-player.html` | док-панель OBS и сам плеер (`?view=player`, копия для стримера — `&role=me`) |
| `server.js` | локальный сервер на `127.0.0.1:8000` |
| `obs-autostart.lua` | скрипт OBS: запускает сервер вместе с OBS и закрывает заказы при выходе |
| `start-server.vbs` | тихий запуск `server.js` без окна консоли |
| `banned-words.json` | списки запрещённых слов |

`data.json`, `data.backup.json`, `plays.json`, `state.json` — личные данные (история, плейлисты, прогресс), в репозиторий не попадают.

## Выпуск новой версии

1. Собрать чистую версию: в папке `redeem-player` — `node build-noproxy.js`.
2. Дописать сверху в `Releases.md` раздел `## v1.2.0` — что изменилось.
3. Запустить `publish.cmd` и ввести тот же номер (`1.2.0`).

Или вручную:

```
git add -A
git commit -m "v1.2.0"
git tag -a v1.2.0 -m "v1.2.0"
git push && git push origin v1.2.0
```

GitHub Actions (`.github/workflows/release.yml`) соберёт `Bzden4ikPlayer.zip` и опубликует релиз. Описание берётся из раздела `## v1.2.0` в `Releases.md`, а если его нет — из сообщения тега. Тег с дефисом (`v1.3.0-beta`) публикуется как тестовая версия. Сайт показывает новую версию сам — без пересборки.
